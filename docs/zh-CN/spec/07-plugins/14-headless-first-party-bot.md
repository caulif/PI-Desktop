# 无界面第一方 Bot 代理层

> **翻译说明：** 本页是与 [英文源规格](/spec/07-plugins/14-headless-first-party-bot) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。

管理员可以通过库选项 `trustedPlugin` 显式组合 pi-bot 服务与 pi-host。
未提供此选项时，原有行为保持不变。仅支持已安装清单中的身份 `local.pi-bot`。
Bot 的私有元数据目录与 Host 数据库、已注册项目分开存储。

Gateway 在请求负载之外提供可信的单用户 principal；工具调用来源只取自 Host
确认归属的活跃回调。变更操作不会从 `confirm`、负载中的 `pluginId` 或
`panelAuthorized` 推导授权。精确的配置、手动 Routine 和检查审批在五分钟后到期；
手动 Routine 令牌的有效期为一分钟，只能消费一次，并绑定意图、Routine、会话和
提示词哈希。

文件操作保留已安装清单声明的作用域及受保护名称的拒绝规则。每次读取最多 512 KiB，
UTF-8 文本严格解码，目录列表最多返回 1,000 个条目，写入替换具有原子性，且不提供
图形界面打开操作。公开导航按已注册的根目录过滤，并向上报告意外的 Host 或文件系统
错误。原生会话在此代理层中以只读形式呈现。

启动、关闭、轮次结束和 Host 重启时，会解除监听器、取消调用上下文、拒绝待处理的
授权并停止调度器计时器。持久化提示词 claim 与 `plugin.promptBeginTurn` 原子绑定。
缺失回调或传输回执既不意味着已有 Work 结果，也不构成重试已完成操作的授权。

## 远程执行节点

`startBotNode` 组合 Host 和已安装的代理层，不启动 Bot 领域。中央服务仍是唯一的
Bot 元数据写入者。配对使用一次性 RACP 票据，将所有者设备凭据保存到管理员选择的
私有文件。`createRemotePluginApi` 将一个已认证的中央写入者连接到节点；另一个
同时连接的写入者会收到 `CONFLICT`。

可选的独立 Host 引导入口 `bot-node.mjs start|pair` 只支持 POSIX 凭据文件。
它要求输入为当前用户拥有、不是链接的普通文件，且不向组或其他用户授予权限；
拒绝共享的输出父目录和已有输出文件，只允许新建专用的、仅所有者可访问的父目录。
在 Windows 上，它在凭据 I/O 前拒绝执行；请使用受管理的 pi-bot 服务 CLI，其
Windows DACL 校验会保护 profile、配对票据和设备令牌。仅在内存中处理凭据的
`pairBotNode` 及 Host 库组合仍支持跨平台使用。

仅提供经过审查的 `botNode/*` 操作目录，不提供任意 Host RPC、插件身份、shell
桥接或授权标志端点。原生工具保留 Host 权限、预算和计划，通过绑定到活跃原生调用及
已连接会话的不透明令牌调用中央 Bot 回调。轮次结束、断开连接和设备撤销均使该令牌
失效。已打开的 RACP 连接也会在每一帧校验设备是否已被撤销。撤销设备还会立即断开
其空闲连接，并阻止之后由服务端发起的请求。撤销移除的是连接授权，不会中止已获准
执行的轮次；需要取消时，应另行取消该精确轮次。

会话地址采用 `node:<actual-host-id>:<native-session-id>`。地址转换只作用于会话
字段和固定操作目录中明确指定位置的会话参数；自由文本、文件内容和模型回答保持
不变。首次连接和重连时的 Host 身份必须与已保存的身份绑定一致。回执丢失不会触发
命令重放。

当设置 `allowOfflineStartup:true` 且已有固定的 `hostId` 时，纯网络故障会得到
明确处于断开状态的适配器。调用以 `HOST_DISCONNECTED` 失败，已注册的工具保留，
有上限的指数退避重连先重新连接同一个 Host，再声明就绪。认证、身份和 schema 错误
不能被当作成功的离线启动。`stop()` 取消重连计时器。

原生审批必须匹配精确的会话、审批 ID、版本及允许的决定。版本零有效。
`agent/abort` 仅在目标为精确的当前活跃轮次时返回 `{ok:true,aborted:true}`；
已过期的轮次返回 `{ok:false,aborted:false}`。自动 Routine 到期事件仍需由 Host
拥有的 occurrence 授权。无人值守的中等风险写入可能等待原生权限；服务不会降低
工具风险以制造自主执行成功的结果。

## 有限执行验收

`scripts/e2e-bot-node.mjs` 使用两个真实且隔离的 Host 进程、真实 Rust 和 sidecar
执行、已认证的 RACP、实际 pi-bot 领域持久化，以及真实 HTTP Gateway。
其确定性的本地 SSE provider 不产生模型调用费用，用于证明协议链路连接正确，
不证明真实模型的判断能力或结果质量。

该探针检查 HTTP 配对和 CSRF、真实 Bot 创建及限定节点的路由、原生审批与过期版本
拒绝、远程文件实际生成及精确 Artifact 下载哈希、忙碌时的队列、取消和停止、浏览器
未运行时的真实定时到期、精确授权后的完成、冷启动离线恢复、跨节点及中央服务重启
后同一 occurrence 的处理，以及已连接设备的撤销。

为避免等待十五分钟，只推进隔离测试数据库的时钟；调度派发、准入、工具执行和
Work 回执仍使用生产代码路径。报告和运行时二进制属于本地产物，并非已提交的凭据，
也不能作为完整产品验收通过的声明。
